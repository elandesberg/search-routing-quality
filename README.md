# Search routing quality — framing doc, simulations, and replication packet

Everything needed to (1) publish the problem-framing document *"Compared to
What?"* and (2) hand an AI work agent the job of specializing it with
production data and running the routing analysis for real.

All numbers in the document's figures are **synthetic** — generated by the
simulations in this repo, invented parameters, shapes-not-levels. The whole
point of the packet is to recalibrate them against production.

## Handoff flow

1. **Push this repo** to the company GitHub (private/internal is fine).
2. **Host the document** at a URL the agent can fetch: enable GitHub Pages on
   `/docs` (the doc is `docs/index.html`), or drop it on the internal wiki —
   it is a single self-contained HTML file.
3. **Fill the repo link**: the doc has one FILL slot referencing "the
   simulation and replication packet" — point it at this repo's URL.
4. **Brief the agent**: paste `AGENT_BRIEF.md` to the work agent with the doc
   URL swapped in, and give it this repo. The brief tells it what to fill,
   what to preserve, and what not to change; `production-replication-packet.md`
   is its work plan (Stage 2b first — it needs no new serving infrastructure).

## File map

| File | What it is |
|---|---|
| `docs/index.html` | The framing document (self-contained HTML, light/dark, 5 figures, marked FILL slots) |
| `AGENT_BRIEF.md` | Instructions for the work agent editing the document |
| `production-replication-packet.md` | Staged work plan for the production analysis (calibration → bias demo → power table → recalibrated sims → live harness) |
| `routing_sim.py` | ε-exploration toy world — backs doc Part Seven (naive-contrast bias; broad-vs-narrow learning curves) |
| `batch_allowlist_sim.py` | Batch A/B toy world — backs doc Part Eight (sparsity; pruning rules; expansion ranking) |
| `allowlist_model_pymc.py` | **Production estimator** (hierarchical Bayes in PyMC/NUTS). Never executed in the authoring sandbox — run the `--demo` cross-check before first real use |
| `hier_bayes_allowlist.py` | Same model, self-contained Gibbs sampler (numpy/scipy only): the validated cross-check and no-PyMC fallback. Also `fit_eb` (cheap first pass) and `fit_eb_t` (a recorded negative result — do not ship) |

## Quickstart

```bash
pip install -r requirements.txt

# mandatory first run: PyMC vs Gibbs cross-check on the shared synthetic world
python3 allowlist_model_pymc.py --demo        # require ≥95% decision agreement

# reproduce the document's figures' numbers
python3 routing_sim.py                        # ~3 min, 24 replications
python3 batch_allowlist_sim.py                # ~1 min, 40 replications

# production run (columns: query_id,n0,c0,n1,c1,f1..fK)
python3 allowlist_model_pymc.py --data logs.csv --cost 0.002
```

Acceptance bars for any production fit: max R-hat < 1.01, min bulk-ESS > 400,
zero divergences, and two-sampler (or two-chain) decision agreement ≥ 95%.
